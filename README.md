# Art Gallery Website

A responsive, SEO-ready static website for GitHub Pages.

## Before publishing
1. Replace `YOUR-USERNAME` in `index.html`, `robots.txt`, and `sitemap.xml` with your GitHub username.
2. Replace `YOUR-EMAIL@example.com` in `index.html` with your email.
3. Replace the sample artwork blocks with your own images if desired.

## GitHub Pages
Create a repository named `art-gallery`, upload these files, then go to:
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

Your URL will be:
`https://YOUR-USERNAME.github.io/art-gallery/`

## Google Search Console
After the site is live, add the exact URL as a URL-prefix property. You can verify using the HTML meta-tag method; paste the verification meta tag inside `<head>` of `index.html`. Then submit:
`https://YOUR-USERNAME.github.io/art-gallery/sitemap.xml`
